Verify the download with the matching `.sha256` file (`sha256sum -c Hubuddy-DeskHub-1.3.0.apk.sha256`).
The first-login credentials and PIN change are described in the main README.

Install: open the APK on the phone and allow "install unknown apps" for your browser or file manager, or
use `adb install -r Hubuddy-DeskHub-1.3.0.apk`. Installing over an older version keeps your settings, and an
earlier single-PC setup becomes the first entry in the new PC list.
